# Creating Visual Studio Project

To create a Visual Studio project in your ASE repo first you must have your repo open in Visual Studio (either when first cloned or reopened by **file->Open Folder**).

Go to **file->new_project** and then set the location to one of the provided directories 

(i.e. 01Assignment1_AIprogramming_3DstarChart, if you don't know where it is right click on your solution in the Visual Studio Solution Explorer and select **Open In File Explorer**). 

Make sure your project uses .net10 or greater.

When you commit changes go to the Git Changes tab, type in your message, click commit and then the push up arrow.
